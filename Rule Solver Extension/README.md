# Math Toolbox

A Chrome and Microsoft Edge extension with eight tabs:

- **Calculator**: evaluates arithmetic expressions with parentheses, powers, and the standard order of operations.
- **Fractions**: adds, subtracts, multiplies, or divides integers, decimals, and fractions exactly.
- **Algebra**: solves one-variable linear equations, including fractional coefficients such as `23a/35 = 200`.
- **Rule finder**: finds the lowest-degree polynomial fitting comma-separated input/output pairs.
- **Geometry**: calculates area and perimeter for rectangles, squares, circles, and triangles; calculates surface area and volume for cubes and spheres.
- **Square roots**: calculates nonnegative real square roots and simplifies integer radicals up to `1,000,000,000,000`.
- **Style**: choose a light or dark theme and customize the accent color; preferences are saved in the browser.
- **Game**: explore, mine, and place blocks in a small first-person 16 × 16 voxel world. Each block has a fixed 16 × 16 pixel texture with visible edges. The game tab widens the popup and shows live FPS. Use WASD/arrow keys or on-screen controls to move, Space or Jump to jump, click the scene to capture the mouse (Escape or Release mouse lets it go), or drag to look around. Left-click breaks blocks and right-click places the selected block. Press E to open a pixel-styled inventory with a player figure, four armor slots, a 2 × 2 crafting area, 27 storage slots, and the nine-slot hotbar; pointer lock is released so you can move the mouse and click a stack. The armor and crafting slots are visual placeholders. Close the inventory with E, Escape, or its button to resume captured-mouse gameplay. The hotbar can be selected with number keys 1–9. Camera rays are cached and the scene is only redrawn when it changes. The world and inventory reset when the extension popup closes.

Displayed numbers use commas for thousands (for example, `12,345`). Input values remain ungrouped so they are easy to enter and parse.

## Install in Chrome or Edge

1. Open `chrome://extensions` in Chrome or `edge://extensions` in Microsoft Edge.
2. Turn on **Developer mode**.
3. Select **Load unpacked**.
4. Choose this `Rule Solver Extension` folder.
5. Open the extension from the browser toolbar and choose a tool tab.

The extension runs locally and does not request access to browser tabs or websites.
